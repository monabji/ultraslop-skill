# Ultraslop

Turn an image into deliberate visual overload: hyper-maximalist, absurdly exaggerated, chaotic, extremely cluttered — while the central subject stays recognizable at every density.

## The one rule

Density is built in **passes**, never one-shot. A single generation of "make it maximal" produces mush. Layered passes produce maximalism.

## Process

### 1. Base pass

Amplify the subject to absurd scale in a monumental, impossible setting (epic landscapes, mythological characters, impossible architecture). Extreme saturation, aggressive contrast, cinematic lighting bursts, lens flares, fire, cosmic energy, gemstones, holographic effects.

### 2. Density pass

Fill every region. No empty space, no clean margins, no breathing room. Add:

- Dozens of slogans, subheadings, absurd fictional quality seals, medals, coats of arms, imaginary certifications, trophies, crowns, flags
- Ornate frames, promotional banners, icons, mascots, characters, 3D objects
- Gigantic condensed 3D metallic/chrome/gold typography with multiple outlines, extrusion, intense shadows, gradients, exaggerated glows — mixed sizes, styles, angles, constantly competing for attention
- Multiple depth layers: foreground / midground / background overlap
- Deliberate informational redundancy: repeat the same information in different forms, ≥5 times

Turn mundane attributes into monumental achievements of historical, planetary, intergalactic, and multiversal proportions.

### 3. Forks — prototype, observe, recommend

At each fork, generate A/B variants, compare what you actually observe, and recommend the winner based on evidence:

1. **Density strategy:** radial siege (elements pile toward the subject) vs. uniform flood.
2. **Type treatment:** chrome/metallic extrusion vs. painted-sign grotesque.
3. **Palette:** full-spectrum clash vs. two dominant hues + neon accents.

Judge forks by which keeps the chaos *legible* in the thumbnail test below, not by taste.

### 4. Leave to the user (taste, not experiments)

- Which reference flavor dominates: lotería/mercado poster, Bollywood hoarding, Kerala truck art, 90s game box art
- How "clean" the subject's hero zone stays

## Verification — report results, don't claim them

Run all three and include the outcomes in your reply:

1. **Thumbnail test:** produce a 64px-wide version of the result. The central subject must still be identifiable. If not, back off the type noise around the hero zone and redo the density pass.
2. **Empty-patch audit:** crop each quarter of the image. Any crop that reads as a *plausible clean advertisement* gets another density pass. Conceptually: no 100×100px region may be flat or sparse.
3. **Redundancy count:** ≥5 elements repeating the same information in different forms (slogan + seal + banner + emblem + medal saying the same thing).

## Calibration

- If the composition seems sufficiently filled → add more elements.
- If it seems exaggerated → exaggerate again.
- If it can be taken in within a few seconds → it is not complex enough.

Visual density: 100%. Saturation: extreme. Ornamentation: unlimited. Negative space: nonexistent. Redundancy: intentional. Aesthetic common sense: deliberately ignored.

## Output

Deliver the final image as a file plus the verification results. When posting an image, provide a `.png` path — never `html_render`.
